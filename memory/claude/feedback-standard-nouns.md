When naming concepts in the Everything Ecosystem (or any of Torian's methods), use the established term with its standard meaning (Moore, NAICS, IRS, Kotler, Prahalad-Hamel, decision rights, etc.). Don't swap a standard term for an invented one.

**Why:** 2026-10-27 he rejected renaming "wedge" to "on-ramp": "in business, those are two different things. We still need to make sure that our nouns are fairly in sync with standards that already exist today." He also dislikes jargon nouns (rejected "sphere": "a venture is a venture").

**How to apply:** for any new noun, cite the standard it follows; if a clash exists, rename the side that is ours/coined, not the standard one. Also check new schema work against frameworks already built in the session (he caught a miss with Product Anatomy).
