- Selection of the sample. A ruling counts wherever it came from, so the number describes the labels Torian chose to rule on, not every label. `SAMPLE.md`, the one drawn sample so far, is stratified by field and value and drawn only from labels that reached Labeled, so it over-weights rare values. A rule applied to a class of ideas (for example every mixed-scope idea) measures that class only. No ruled label was held back by the gate, so the two columns compare the same labels and cannot differ yet; the effect of the symbolic checks shows only once rulings cover labels the gate rejected.

- Exact match. A label agrees only when its value equals the ruling. A relation list that shares some items with the ruling counts as a miss, and a scope with the right scope but another attachment counts as a miss.
- One run. Every proposal comes from one proposals file, so the number describes that run, not a proposer in general.
