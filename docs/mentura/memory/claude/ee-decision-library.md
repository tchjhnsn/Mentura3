Torian's idea (2026-10-29 05:24Z, his words summarized): Naive needs a decision library, as a component library is to React. Items are problem templates per venture function that encode the goal, the hidden decisions and the premise, and challenge false dichotomies. They never encode the answer, for freshness. Fetched by an LLM, a template sets how it reasons. Freshness skills look up the latest solutions at use time. His example: "I need investors to scale but don't want to give up control" = two decisions (take investment? give up control?) + goal (scale); attack the premise (false dichotomy?).

Claude's draft (not accepted): item called a "frame"; fields triggers, goal, hidden_decisions, premises, attacks, reframe, composes, props, freshness {look_for, filter_by, max_age_days, cite}, reasoning, emits decision-record, cases. Premise attacks as "hooks" (false-dichotomy, split-the-dimension, test-the-goal, sequence-not-choose, who-solved-this, invert). Premises become yes/no Jev propositions. Freshness spec in package, the skill that runs it in the kit. Design page: https://claude.ai/artifact/88Hfgr5QFG2SP4dwDE9n94 . Thread cmsg_01TRojivaFzywKqAKrsycdv81vDy1VKeKfWw3ZBzrRwUwy.
