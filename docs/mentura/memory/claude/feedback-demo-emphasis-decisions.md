Torian, 2026-10-29 01:47Z: founder-words matching is good but obvious, so it is not a demo focus, and it must NOT be a gating function (founders want to write with AI and let the AI's words carry). The key emphasis is the Decision Docket and strong evidence that it ranks decisions properly, i.e. that its top items really are the best next steps. Rank decisions within each venture function, AND rank functions against each other to show which function needs the most attention at each moment. The top function can change many times in a day as decisions are made, and one decision can outweigh every other function's decisions combined.

**Why:** "non-obvious insight" is a judging criterion; decision prioritization is the differentiator.
**How to apply:** demo, evals and Jev judges should center on decision ranking quality; drop founder_words as a gate. Related: [[ee-demo-plan]], [[feedback-decision-docket]], [[ee-hackathon-aitx-2026]].
