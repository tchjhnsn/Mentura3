# Mentura docs

Mentura's company docs, moved here from tchjhnsn/mentura's `docs/` with their history when Reflect became the monorepo for Reflect and Mentura (2026-11-24).

| Folder | Holds |
|---|---|
| `decisions/decisions.json` | The decision log (`EE-NNN`) |
| `design/` | Designs, including the ontology program's plan and preserved frameworks |
| `reviews/` | Dated reviews and the ontology program's ledgers, proposals and reports |
| `research/`, `master/`, `memory/`, `upgrades/` | Research, the master article, agent memory and upgrade notes |

The ontology program's scripts are in [`tools/ontology/`](../../tools/ontology/README.md). These docs name paths as they were in Mentura (`scripts/`, `platform/`, `console/`); in this repository those are `tools/ontology/`, `packages/platform/`, and the retired console.
